# Telegram Android — воспроизведение и исправление багов

Независимый проект для проверки обращений на реальных устройствах и подготовки патчей к [Telegram Android](https://github.com/DrKLO/Telegram). Исходная база для первого разбора — [13.2.1 (7291)](https://github.com/DrKLO/Telegram/commit/7be672ead283d022812d75c729d3a04dd4c2a2c6). Для каждого прогона указываем фактическую версию приложения.

## Текущая работа

[№67474](bugs/67474/README.md) проверен на iQOO и отправлен в [PR #2270](https://github.com/DrKLO/Telegram/pull/2270). [№67017](bugs/67017/README.md) воспроизведён на Pixel 8 Pro с Telegram 13.1.1. На iQOO с 13.2.1 в проверенном сценарии текст обновил цвет корректно.

## План

1. Начать с №67474. Один и тот же текст вставить из буфера в обычный и расширенный редакторы. Сравнить черновики до отправки.
2. Затем проверить №67017 (тема оформления) и №67406 (OGG). Для остальных карточек порядок и нужное оборудование указаны в [очереди](backlog.md).
3. Для воспроизводимого бага сохранить минимальный пример, шаги, версию ОС и клиента, ожидаемый и фактический результат в его папке. Если требуется конкретная модель, отметить это отдельно.
4. Изолировать причину на зафиксированном коммите upstream и подготовить небольшой diff. Повторить тот же тест на исходной и исправленной сборках. Для уже открытого PR проверить существующую ветку.
5. Передать upstream проверенный результат и записать ссылку и статус. Отдельно отмечать воспроизведение, локальную проверку патча и принятие изменения upstream.

## Рабочие устройства

Pixel 8 Pro (Android 17) и iQOO I2407 (Android 15). При двух подключённых устройствах команды запускаются с явным выбором через adb -s. Доступность функций зависит также от версии клиента и аккаунта. Сырые данные устройств остаются в локальном каталоге private/. В карточках публикуются синтетические примеры и выбранные диагностические данные.
