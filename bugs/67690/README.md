# После записи голосового TalkBack теряет нижнюю часть чата

[Обращение №67690](https://bugs.telegram.org/c/67690) · Open на 10 ноября 2026. В очереди на воспроизведение.

## Проверка

Зафиксировать запись голосового, остановить и удалить тестовую запись. Проверить доступность последних сообщений и панели ввода на ощупь.
