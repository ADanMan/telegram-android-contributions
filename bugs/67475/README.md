# Выделение и удаление в расширенном редакторе

[Обращение №67475](https://bugs.telegram.org/c/67475)

Статус проекта: ожидает воспроизведения.

## Проверка

Повторить выделение одного диапазона в длинном черновике с фиксированной клавиатурой; сравнить обычный ввод.

Автор воспроизвёл сбой на Redmi Note 13, Android 15, Telegram 13.1.1 (72371), и приложил видео длительностью 46 секунд. Для сравнения на iQOO установлен официальный Telegram 13.2.1. В одном длинном тестовом черновике проверить выделение внутри абзаца и через границу двух абзацев. Для каждого случая сверить оставшийся текст после удаления. Проверка на iQOO ещё не выполнена.
