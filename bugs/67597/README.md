# В «Показать все медиа» отсутствуют фотографии

[Обращение №67597](https://bugs.telegram.org/c/67597)

Статус проекта: воспроизведено расхождение между концом сетки и просмотрщиком на общедоступных видео.

## Проверка

На одном канале сравнить одни и те же старые фото в просмотрщике и сетке. Проверить догрузку страниц.

## Контроль на публичном канале

10 ноября 2026, iQOO I2407, Android 15, Telegram 13.2.1. Открыли [фотографию №458 в Telegram News](https://t.me/telegram/458), затем More options → Show All Media. Счётчик показал 244 медиа. Прокручивали сетку вниз до остановки. Последние три быстрых свайпа дали одинаковый отпечаток области миниатюр. Спустя дополнительную паузу четыре медленных свайпа также не изменили эту область.

При повторном открытии последней ячейки получили [Story Albums, №398](https://t.me/telegram/398). Горизонтальный свайп в открытом просмотрщике привёл к более старому [Public Post Search, №397](https://t.me/telegram/397). Таким образом, просмотрщик показал как минимум одну публикацию за наблюдаемой границей сетки. Счётчик 244 сам по себе не показывает число отсутствующих элементов. Обе граничные публикации — видео. Для жалобы именно о фотографиях нужен отдельный контроль с двумя фотографиями у границы.

[Обработчик Show All Media](https://github.com/DrKLO/Telegram/blob/7be672ead283d022812d75c729d3a04dd4c2a2c6/TMessagesProj/src/main/java/org/telegram/ui/PhotoViewer.java#L5113-L5125) создаёт MediaActivity. [Догрузка сетки](https://github.com/DrKLO/Telegram/blob/7be672ead283d022812d75c729d3a04dd4c2a2c6/TMessagesProj/src/main/java/org/telegram/ui/Components/SharedMediaLayout.java#L4618-L4638) зависит от loading, endReached и max_id. Причина остановки пока не установлена. Следующий шаг — зафиксировать эти три значения на границе страницы и сравнить ответ кеша с сетевой страницей. Для воспроизведения достаточно публичных ссылок выше.
