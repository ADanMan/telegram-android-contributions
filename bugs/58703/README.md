# Рассинхрон в кружках и выбор рекордера

[Обращение №58703 и ответ Admin Dog](https://bugs.telegram.org/c/58703). На Pixel 8 Pro с Telegram 13.1.1 задержка звука у отметки 48 секунд составила 9,435 с на старом пути Camera2 и 0,072 с после включения нового рекордера. На iQOO I2407 в записях с вручную выбранным новым рекордером нарастающего рассинхрона не обнаружили. Команда Telegram подтвердила, что новый рекордер уже включён. Это сравнение двух существующих реализаций. Собственного исправления по этой карточке нет.

## Контроль настроек по умолчанию

В официальных исходниках 13.2.1 сохранённый локальный выбор имеет приоритет. Если ключ отсутствует, клиент использует новый рекордер, пока серверная конфигурация аккаунта не отключила его. [Выбор реализации](https://github.com/DrKLO/Telegram/blob/7be672ead283d022812d75c729d3a04dd4c2a2c6/TMessagesProj/src/main/java/org/telegram/ui/Components/InstantCameraViewBase.java#L47-L62).

Повторное нажатие переключателя записывает явное значение, в том числе когда оно совпадает с серверным. Для проверки чистого состояния на iQOO подходит отдельный профиль Android с официальным приложением, без восстановления настроек, и с тем же аккаунтом. После получения конфигурации записать один кружок с таймером, определить реализацию по журналу этой записи и сравнить задержку первых и последних вспышек в отправленном файле. Проверки в чистом профиле пока не было. [Запись локального выбора](https://github.com/DrKLO/Telegram/blob/7be672ead283d022812d75c729d3a04dd4c2a2c6/TMessagesProj/src/main/java/org/telegram/utils/settings/BooleanSetting.java#L48-L60).
