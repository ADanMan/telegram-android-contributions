# Telegram Android — очередь для проверки

10 ноября 2026. Во всех 20 карточках проверен статус Open. Описание симптомов взято из трекера. Очерёдность и тесты предложены для Pixel 8 Pro и iQOO I2407. Пока это кандидаты. Собственных патчей или подтверждения воспроизведения этих 20 карточек нет. Ранее исследованный №58703 в счёт не входит.

| Очередь | Карточка | Как проверить и где искать дальше |
|---|---|---|
| 1 | [При вставке пропадают пустые строки](https://bugs.telegram.org/c/67474) | Скопировать три абзаца с пустой строкой. Вставить один и тот же буфер в обычный и расширенный редакторы. Сравнить полученный текст до отправки и пройти оба обработчика вставки. |
| 2 | [Цвет текста в поле ввода после смены темы](https://bugs.telegram.org/c/67017) | Набрать черновик и сменить системную тему в открытом чате. Сравнить цвет со свежим открытием того же чата. |
| 3 | [Теги OGG пропадают после загрузки](https://bugs.telegram.org/c/67406) | Создать короткий OGG с известными TITLE и ARTIST, сравнить исходник, скачанный файл и подпись в клиенте. Так можно различить потерю тегов и ошибку их отображения. |
| 4 | [Текст под панелью закрепа при свайпе ответа](https://bugs.telegram.org/c/67455) | Закрепить сообщение в тестовом чате, частично прокрутить текст под панель и записать свайп. Сравнить с GIF. |
| 5 | [В «Показать все медиа» отсутствуют фотографии](https://bugs.telegram.org/c/67597) | На одном канале сравнить одни и те же старые фото в просмотрщике и сетке. Проверить догрузку страниц. |
| 6 | [Выделение и удаление в расширенном редакторе](https://bugs.telegram.org/c/67475) | Повторить выделение одного диапазона в длинном черновике с фиксированной клавиатурой; сравнить обычный ввод. |
| 7 | [Автовспышка задней камеры](https://bugs.telegram.org/c/67434) | Проверить отдельно фото и видео при постоянном слабом освещении. Записать выбранный API, доступные режимы и фактический запрос камеры. |
| 8 | [Эмодзи смещаются при раскрытии блока](https://bugs.telegram.org/c/67099) | Сравнить положение текста, обычного и кастомного эмодзи покадрово. Для теста нужен rich message с details. |
| 9 | [Пустые матрицы LaTeX](https://bugs.telegram.org/c/67432) | Сравнить на Android и Desktop один rich message из Bot API с простой формулой и матрицей pmatrix. |
| 10 | [Мерцание при появлении голосового сообщения](https://bugs.telegram.org/c/67659) | Сравнить чат с голосовым и текстовым сообщением без воспроизведения. Если мерцание не видно в записи экрана, снять дисплей вторым телефоном. |
| 11 | [Отложенные сообщения исчезают из списка](https://bugs.telegram.org/c/67025) | В тестовом чате проверить текст и голосовое по отдельности и в указанной в карточке последовательности. Сверить со вторым клиентом. |
| 12 | [Повторное скачивание при сохранении файла](https://bugs.telegram.org/c/66967) | Использовать заранее скачанный небольшой файл. Проверить сохранение при наличии локальной копии и затем офлайн. |
| 13 | [Повторная публикация неизменившихся уведомлений](https://bugs.telegram.org/c/67664) | В двух тестовых чатах менять только одно уведомление. Сравнить ключи и время обновления обоих. |
| 14 | [Медиа в галерее при отключённом сохранении](https://bugs.telegram.org/c/67375) | Повторить сценарий карточки с двумя тестовыми аккаунтами и безличным изображением. Проверить наличие файла в MediaStore после каждого шага. |
| 15 | [Неудачная отправка GIF блокирует секретный чат](https://bugs.telegram.org/c/67097) | Нужны два тестовых аккаунта. После управляемого сбоя проверить доставку следующего сообщения в обоих направлениях. |
| 16 | [Запрошены 60 FPS, кружок записан при 30 на Galaxy S22 Ultra](https://bugs.telegram.org/c/67330) | У нас есть сравнительные замеры Pixel и iQOO. Для вывода о Samsung нужны его Camera2 ranges и допустимые комбинации потоков. |
| 17 | [Поворот фронтального кружка на 90° в альбомном режиме](https://bugs.telegram.org/c/67570) | На телефонах проверить общий путь поворота; точное воспроизведение заявлено на Samsung Galaxy Tab S12 Ultra. |
| 18 | [Фронтальная стабилизация кружков на OnePlus 15](https://bugs.telegram.org/c/66968) | Сравнить поддерживаемые и запрошенные режимы EIS при тех же потоках и FPS. Для приёмки нужен OnePlus. |
| 19 | [Bluetooth-гарнитура не подхватывается во время звонка](https://bugs.telegram.org/c/67630) | Есть [PR #2257](https://github.com/DrKLO/Telegram/pull/2257). Проверять его на реальной гарнитуре: подключение во время звонка, смена выхода, отключение. |
| 20 | [Репост rich text в Stories даёт пустой стикер](https://bugs.telegram.org/c/67135) | Есть [PR #2231](https://github.com/DrKLO/Telegram/pull/2231). Проверить предпросмотр Stories и меню пересылки одного rich text поста. |

Репозиторий: https://github.com/DrKLO/Telegram (master). GitHub Issues выключены. Перед правкой проверить актуальный статус карточки, полный тред и совпадения в открытых и закрытых PR по номеру и симптому. Перед публикацией сверить правила проекта. Первые три номера не дали совпадений при поиске PR по номеру, но совпадение по описанию ещё возможно.
